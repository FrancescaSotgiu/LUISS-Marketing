# Basics of Marketing · LUISS Business School Amsterdam

Course site for Prof. Francesca Sotgiu. Static pages, no build step.

| File | What it is |
|---|---|
| `index.html` | The course site: lessons, mini-cases (additional material), group project, worked example, quizzes and the AI agent lab |
| `tutorial.html` | Slide tutorial: how to build your marketing agent (with a script per slide for the video) |

## Publish on GitHub Pages

1. Upload both HTML files to the root of the repository.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. The site is live at `https://<your-username>.github.io/<repository-name>/` after a minute or two.

## Add the tutorial video

In `index.html`, find the comment "When the video is online…" in the AI lab section, paste the video link in `href`, and delete the word `hidden`.
